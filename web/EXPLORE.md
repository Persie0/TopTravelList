# Map-first Explore mode

The Explore tab opens ranked sights with an overall score of 90 or higher. Switch between 95+, 90+, 80+, top 25/100/250 and all ranked presets. Use existing geographic, kind, category and search filters to refine results. The map-area checkbox restricts the sidebar to currently visible destinations; turn it off for all filtered map destinations. Top-N limits are calculated before viewport filtering within the current ranking scope. List-only mode shows all filtered matches.

Google Images links use the destination name and country, open in a separate tab, and do not fetch or store images. Existing Maps links remain available.

Run `npm test` and `npm run build` in `web/` to validate the frontend.
