# Intelligent planning and personalized rankings

Routes & trips now includes a constraint-based itinerary optimizer, great-circle corridor and detour finder, base-city recommendations, transport-mode comparison, and score/cost analysis. The solver is a bounded greedy insertion heuristic (300 candidates, maximum 40 stops). Input time, distances and costs are estimates, not real road routing, timetables or live prices. It treats each transfer and visit as an indivisible active-time block; an existing first stop and optional final stop are fixed. The group-cost inputs are converted to the existing trip studio's per-person budget and straight-line distance convention when applying a proposal. Actual access, opening hours, costs and connections need independent confirmation.

The For you tab supports local saved profiles, configurable category and core-dimension weights, editorial-score blending, weighted coverage thresholds, geographic/search/type filters, favorites and optional weight suggestions from favorites. Missing category values are excluded from the weighted mean, never converted to zero. The weighted coverage threshold controls how much of the requested preference weight must be known. With no active interests, rankings fall back to editorial scores. Personal scores do not modify the source dataset. Climate, accessibility and physical difficulty are not offered because the current dataset lacks those fields. Profile storage is local to the browser.

Validation: run npm test and npm run build from web/. New tests live in scripts/intelligent-trip.test.mjs and scripts/personal-rankings.test.mjs.
