# SO — Somalia sights: individual worldwide reviews

2026-11-25. Initial worldwide V2 inventory. SO is the existing repository country code; Somaliland-administered destinations are included without implying common administration. Consult [FCDO](https://www.gov.uk/foreign-travel-advice/somalia): all travel discouraged except Awdal, Maroodijeh and Sahil, where all but essential travel is discouraged. Scores describe historical documented experiences, not safety or admission. Representative points not entrances; several provisional. Current peer YAML spot-checked for Kashgar, Hallstatt, Phnom Penh, Poipet, Mogao, Carnuntum, Okavango, Suncheon and Railay; remaining peers not checked. Sources inspected at inventory level or linked; no fully independently verified claim-level status asserted.
